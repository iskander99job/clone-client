# Кратер

Пошаговая браузерная дуэль с базукой, ветром и разрушаемым грунтом. Для тренировки можно сыграть с ботом.

## Запуск онлайн-версии

Нужен Node.js 24. Клонируй оба репозитория в одну папку:

```sh
git clone https://github.com/iskander99job/clone-client.git
git clone https://github.com/iskander99job/clone-backend.git
(cd clone-client && npm ci && npm run build)
(cd clone-backend && npm ci && npm start)
```

Открой `http://localhost:3000`. Нажми «Позвать друга» и открой приглашение в другом браузере или приватном окне. Друг нажимает «Вступить в дуэль», затем первый игрок может стрелять. По завершении выстрела ход переходит сопернику, который при открытии увидит повтор. Ссылка на матч остаётся в адресной строке. Место игрока сохраняется в браузере, где он вступил в матч.

Для игры с разных устройств открой сервер по адресу, доступному обоим. Для публичного доступа нужен хостинг с HTTPS и постоянным диском для базы SQLite.

## Разработка

Для разработки клиента запусти `npm run dev` в `clone-client`. Запросы к API Vite направляет на сервер на порту 3000. Тренировка работает и без запущенного сервера.

Правила и физика находятся в `src/duel.ts`. Phaser рисует игру, Rapier 2D считает физику, d3-contour строит границы грунта. В онлайне клиент воспроизводит кадры и состояние, полученные от сервера.
