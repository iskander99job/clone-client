# Кратер

Браузерная игра. По умолчанию открывается фруктовая карта с векторным передним планом. Плоская тестовая площадка доступна по адресу `?map=flat`. Для «Фруктового острова» добавь к адресу `?map=fruit`, для «Каменного карьера» — `?map=quarry`.

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Открой адрес из терминала, обычно `http://localhost:5173`. Для статической сборки выполни `npm run build`. Готовые файлы находятся в `dist/`.

## Управление персонажем

Удерживай ← или → в интерфейсе или на клавиатуре, чтобы идти. Кнопки прыжка отправляют персонажа вперёд или назад относительно его взгляда. Пробел запускает прыжок вперёд, когда фокус находится на карте. После падения в воду персонаж возвращается на старт.

Открой ящик, чтобы взять или убрать базуку. Стрелки ↑ и ↓ меняют угол, а кнопка прицела выпускает ракету.

## Управление картой

Колёсико или щипок двумя пальцами меняют масштаб. При приближении карту можно перетаскивать мышью или одним пальцем. Масштаб ограничен диапазоном от 1× до 1,75×, а перемещение ограничено краями карты.

## Карта

За островом находятся цвет неба, дальний сад с плавным переходом прозрачности и отдельный слой облаков. Полупрозрачная вода лежит поверх основания острова и продолжается до нижнего края экрана.
