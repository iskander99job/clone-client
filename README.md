# Кратер

Браузерная игра. По умолчанию открывается «Карточный домик». Прежняя фруктовая карта с векторным передним планом доступна по адресу `?map=fruit-foreground`. Плоская тестовая площадка доступна по адресу `?map=flat`. Для «Фруктового острова» добавь к адресу `?map=fruit`, для «Каменного карьера» — `?map=quarry`.

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Открой адрес из терминала, обычно `http://localhost:5173`. Для статической сборки выполни `npm run build`. Готовые файлы находятся в `dist/`.

## Управление персонажем

Удерживай ← или → в интерфейсе или на клавиатуре, чтобы идти. Кнопки прыжка отправляют персонажа вперёд или назад относительно его взгляда. Пробел запускает прыжок вперёд, когда фокус находится на карте. В тренировке после падения в воду персонаж возвращается на безопасную точку. Если опора разрушена или место занято, игра проверяет остальные точки. Если свободной опоры нет, персонаж ждёт появления доступной точки.

Открой ящик, чтобы взять или убрать базуку. Стрелки ↑ и ↓ меняют угол, а кнопка прицела выпускает ракету.

## Управление картой

Колёсико или щипок двумя пальцами меняют масштаб. При приближении карту можно перетаскивать мышью или одним пальцем. Масштаб ограничен диапазоном от 0,75× до 1,75× (обычный масштаб — 1×), а перемещение ограничено краями карты.

## Карта

У «Карточного домика» есть разрушаемый грунт и отдельный векторный фон, который заполняет экран пропорционально и не зависит от камеры. В `src/map_config.json` у каждой карты заданы размеры мира и уровень воды `waterY`. Полупрозрачная вода лежит поверх основания острова и продолжается до нижнего края экрана.

### Масштаб и положение грунта

- `terrainTransform.scale` одинаково масштабирует обе оси относительно нижнего центра непрозрачной части маски. `offsetX` и `offsetY` затем сдвигают грунт в мировых единицах. Положительный Y направлен вниз. Без настройки применяется масштаб 1 и нулевое смещение.
- `terrainSize` задаёт размер исходного холста грунта в мировых единицах до преобразования. По умолчанию это размер мира.
- У точек появления Y обозначает положение стоп. При `spawnCoordinateSpace: "terrain"` координаты задаются в единицах исходного холста `terrainSize` и перемещаются вместе с грунтом. При `"world"` они задаются в итоговых мировых координатах.
