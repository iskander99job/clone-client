# Кратер

Браузерная пошаговая дуэль с ботом. Выбери угол и силу, выстрели из базуки и дождись ответного выстрела. Ветер отклоняет ракету. Попадания оставляют кратеры и отбрасывают персонажей.

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Открой адрес из терминала, обычно `http://localhost:5173`. Для статической сборки выполни `npm run build`. Готовые файлы находятся в `dist/`.

## Карта

Фруктовый остров состоит из трёх слоёв. Дальний сад загружается из `src/assets/fruit-orchard.webp`. Прозрачность `src/assets/fruit-island.png` задаёт маску грунта. После взрыва d3-contour строит контуры оставшегося грунта для коллайдеров Rapier, а Phaser вырезает кратер в изображении. Полупрозрачная вода рисуется поверх острова, персонаж выбывает при падении за линию воды.
