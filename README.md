# Кратер

Браузерная сцена с фруктовым островом.

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Открой адрес из терминала, обычно `http://localhost:5173`. Для статической сборки выполни `npm run build`. Готовые файлы находятся в `dist/`.

## Карта

Фруктовый остров состоит из трёх слоёв: дальнего сада (`src/assets/fruit-orchard.webp`), острова (`src/assets/fruit-island.png`) и полупрозрачной воды поверх основания острова.
