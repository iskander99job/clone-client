# Кратер

Браузерный прототип пошаговой дуэли. Игрок управляет Мятой, бот — Искрой. Установи угол и силу, затем нажми «Выстрелить». Ветер задаётся случайно перед каждым ходом и отклоняет ракету в указанную сторону. Бот учитывает ветер и отвечает после окончания твоего хода. Попадания отнимают здоровье, отбрасывают персонажей и оставляют кратеры. Побеждает последний оставшийся в живых.

## Запуск

Нужен Node.js 22.12+ или 24.

```sh
npm ci
npm run dev
```

Открой адрес из терминала. Сборка: `npm run build`. Статические файлы находятся в `dist/`.

## Устройство

- `src/duel.ts` содержит правила дуэли. Rapier 2D рассчитывает движение и столкновения. После взрыва d3-contour строит контуры маски грунта для обновления коллайдеров.
- `src/main.ts` рисует мир через Phaser и связывает с ним элементы управления.
